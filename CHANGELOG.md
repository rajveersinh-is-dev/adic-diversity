# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-05

### Added
- Core library for computing 2-adic valuation diversity of subset sums
- Search algorithms: greedy construction, hill climbing, simulated annealing
- Explicit constructions: odd numbers, powers of two
- Systematic experiments for k=1..16
- Comprehensive test suite
- LaTeX paper with results, conjectures, and open problems
- Figures: f(k) vs k, ratio f(k)/k, valuation spectra
- Reproducible experiment scripts

### Results
- Best known f(k) for k=1..16
- Conjecture: f(k) ~ 1.5k, lim f(k)/k = 3/2
- Consecutive spectra identified for k in {3,4,6,8,12,14}
